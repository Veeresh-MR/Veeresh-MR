| Product | Platform / Stack | Description & Live Link |

| **NEET Quest** | Flutter, Riverpod, Supabase, PostgreSQL | Medical entrance exam platform serving a **235,000+ question bank** and 31k+ flashcards. | **Arrow Paint** | Flutter, 2D Game Loop, Audio Engine | Relaxing offline tap-away puzzle and pixel art coloring game featuring custom collision physics, obstacle mechanics, dynamic haptics, and a built-in *Pixel Studio* level canvas. <br/>👉 **[View on Google Play](https://play.google.com/store/apps/details?id=com.thequeststudio.arrowpuzzle.pixelart.offline.game)** |
| **Pragathi Dental Care** | React, Node.js, REST APIs, Render | Official commercial web platform built and sold to a practicing clinic; live in production across 2 physical clinic branches with automated booking workflows. <br/>👉 **[Live Deployment](https://pragathi-dental-care.onrender.com)** |
